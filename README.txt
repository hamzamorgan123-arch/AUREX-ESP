AUREX Esports website

GitHub Pages upload instructions:
1. Extract this ZIP.
2. Open your AUREX-Esports GitHub repository.
3. Add file > Upload files.
4. Upload index.html, style.css, and script.js together (not the enclosing folder).
5. Commit changes to the main branch.
6. In Settings > Pages, choose Deploy from a branch, main, /(root), then Save.
7. Wait for the Pages deployment to finish.

Replace aurexesports@gmail.com in index.html with your official contact email before launch.
