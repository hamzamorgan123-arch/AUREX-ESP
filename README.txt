AUREX ESPORTS WEBSITE

FILES
- index.html: public website
- style.css: design
- script.js: public event/news display
- site-data.json: public content (events, news, Discord, optional public contact)
- admin.html and admin.js: browser-based editor

FIRST INSTALL
1. Extract this ZIP.
2. Open your GitHub repository: https://github.com/hamzamorgan123-arch/AUREX-ESP
3. Upload ALL files from this extracted folder into the repository root (not inside another folder). If GitHub asks, replace the old index.html/style.css/script.js.
4. Commit the upload to the main branch.
5. Open https://hamzamorgan123-arch.github.io/AUREX-ESP/ and https://hamzamorgan123-arch.github.io/AUREX-ESP/admin.html

HOW TO UPDATE SCRIMS / TOURNAMENTS
1. Open the website's /admin.html page.
2. Add or edit event titles, game, event type, date, time + timezone, region/server and details. Add news if needed.
3. Click DOWNLOAD UPDATED SITE DATA. It downloads site-data.json.
4. Go to GitHub repository -> Add file -> Upload files.
5. Upload the downloaded site-data.json into the ROOT of the repository. Replace the old file when asked.
6. Click Commit changes. After GitHub Pages deploys, refresh the public site. Changes can take a minute or two.

IMPORTANT LIMITATION
GitHub Pages is static hosting. This editor does not have a secure login and cannot publish directly to the public site. It downloads the content file; you publish it by uploading that file to GitHub. Anyone can view the public data file. Do not put passwords, private player information, or confidential details in it. Do not enter any password or GitHub token into the editor.

The email/Discord/contact fields become public. Only publish contact details and invite links you are comfortable sharing. The Discord link and phone are blank until you add them.
